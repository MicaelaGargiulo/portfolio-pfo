# Portfolio-PFO

## Descripción

Este proyecto corresponde a la PFO1 de la materia. Consiste en una landing page de portafolio personal desarrollada con HTML y CSS.

La página presenta información personal, habilidades, un proyecto realizado durante mi formación, intereses y una sección de contacto. También incluye un enlace a mi perfil de GitHub.

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- GitHub
- Vercel

## Decisiones de diseño

Para el diseño del portfolio elegí una estética sencilla, clara y profesional, buscando que la información fuera fácil de leer y navegar.

Utilicé una estructura organizada mediante diferentes secciones y un menú de navegación. Para la sección "Sobre mí" incorporé una imagen relacionada con el desarrollo web y la ubiqué junto al texto para generar una composición visual más equilibrada.

También utilicé Flexbox para organizar los elementos y agregué un diseño responsive para que la página pueda adaptarse a diferentes tamaños de pantalla.

Se incorporaron transiciones en los enlaces del menú para generar una interacción visual al pasar el cursor sobre ellos.

## Publicación

El proyecto fue publicado utilizando Vercel.

**URL:** https://portfolio-pfo.vercel.app/

## Uso de inteligencia artificial

Durante el desarrollo del proyecto utilicé ChatGPT como herramienta de apoyo.

La herramienta fue utilizada principalmente para comprender conceptos de HTML y CSS, resolver dudas y recibir explicaciones de una manera que pudiera entender con mayor facilidad. También fue utilizada como apoyo durante la construcción, revisión y modificación del código.

Las sugerencias proporcionadas por la IA fueron revisadas y adaptadas durante el desarrollo del proyecto. Las decisiones relacionadas con el contenido, la organización de las secciones y el diseño visual fueron revisadas y modificadas por mí.

La experiencia que tengo con herramientas de inteligencia artificial consiste en usarlas como apoyo para estudiar y comprender temas que me resulten difíciles.

La herramienta que utilicé fue ChatGPT, en su plan gratuito.
